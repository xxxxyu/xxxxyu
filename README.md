# Hi, I'm Xiangyu Li (李翔宇) 👋

I'm a 5th-year Ph.D. candidate at the [Institute for AI Industry Research (AIR), Tsinghua University](https://air.tsinghua.edu.cn/en/), advised by [Prof. Yunxin Liu](https://yunxinliu.github.io) and working closely with [Prof. Ting Cao](https://tingcao952.github.io). I work on **on-device AI** and **embodied AI**, with a current focus on efficient deployment of embodied foundation models (VLAs and WAMs) and self-evolving physical intelligence. ## Selected work

### Embodied AI

First / co-first:

- **[OxyGen](https://air-embodied-brain.github.io/OxyGen) (NeurIPS 2026):** unified KV Cache management for VLA inference under multi-task parallelism
- [Cosmos Lite](https://github.com/xxxxyu/cosmos-lite): efficient inference and parallel rollout for Cosmos 3 robot policies on consumer-grade GPUs
- [ActProbe](https://air-embodied-brain.github.io/actprobe): a lightweight action-space probe for early failure detection of robot policies

Collaborations:

- **[Zetta ζ](https://air-embodied-brain.github.io/zetta) (1k+ stars🔥):** an efficient closed-loop embodied harness for self-evolving physical intelligence
- [Zeva](https://air-embodied-brain.github.io/Zeva): in-context causal learning (ICCL) for generalizable embodied manipulation
- [EmbodiSkill](https://github.com/air-embodied-brain/EmbodiSkill) (integrated into [Microsoft/SkillOpt](https://github.com/microsoft/SkillOpt)): a training-free skill-aware framework for self-evolving embodied agents
- [Embodied.cpp](https://github.com/SEU-PAISys/Embodied.cpp) (100+ stars): a portable inference runtime for embodied AI models on heterogeneous robots
